# Fruitful Multiplication Adventures

Create a webapp so kids can learn using a gamificating approach how to multiply using different fruits and  levels of complexity starting at 0x0 (zero times zero) and finishing at 10x10 (ten times ten).

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://fruit-math.lovable.app
